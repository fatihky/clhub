> 本次升级主要的内容在于：

### 1. 支持 echarts v5 最新版本

![image.png](https://cdn.nlark.com/yuque/0/2021/png/86342/1612763934661-f1a4024a-fe6d-47bb-9fd5-60d078be1dbc.png#align=left&display=inline&height=127&margin=%5Bobject%20Object%5D&name=image.png&originHeight=254&originWidth=1084&size=109530&status=done&style=none&width=542)

### 2. 完全 typescript

之前是在 React 0.14 时代，还是使用 props-types 校验 props，然后 ts 类型定义单独自己手写，也非常痛苦。**所以这次直接使用 ts 写，自动生成 类型定义 文件。**

### 3. 单测覆盖率

之前使用 [jest-canvas-mock](https://github.com/hustcc/jest-canvas-mock) 进行单元测试，毕竟是 mock 而不是真实运营，所有一些逻辑测试不到，覆盖率一直提不上去。

所以这次换成了[ jest-electron](https://github.com/hustcc/jest-electron)，真实运行，覆盖率直接提升到 ![](https://img.shields.io/coveralls/hustcc/echarts-for-react/master.svg#align=left&display=inline&height=20&margin=%5Bobject%20Object%5D&originHeight=20&originWidth=96&status=done&style=none&width=96)，运行也改成使用 GitHub action 了。当然  jest-electron 这个模块，也是为了给 AntV 系列技术栈做单测，而开发的轮子，个人觉得还是挺好用的。

### 4. 全新官网

之前的官网是自己初学 React 的时候，完全自己搭建的，没有 lint、ci，代码凌乱，样式也不好看。所以这次直接使用 [dumi](https://github.com/umijs/dumi) 这个库自动生成，网站全部 markdown 开发，也方便大家遇到官网 typo，直接一键提交 PR。

![image.png](https://cdn.nlark.com/yuque/0/2021/png/86342/1612764445642-66119a3e-29c2-4ca6-964a-24d32b56621d.png#align=left&display=inline&height=856&margin=%5Bobject%20Object%5D&name=image.png&originHeight=1712&originWidth=3334&size=695559&status=done&style=none&width=1667)


同时 Example 实例也可直接一键导航到其他代码编辑工具上。

项目很简单，概念也很简单，所以直接 Readme 作为 document，但是之前的文档结构、样式排版比较凌乱，所以按照现在的个人审美，重新写了写！
