## Highlights

- **Python support**: Official [Playwright for Python](https://github.com/microsoft/playwright-python) is ready for preview!
  - Use the [Pytest plugin](https://github.com/microsoft/playwright-pytest) to write your end-to-end tests in Python.
- **Validate system dependencies**: Playwright now automatically checks for browser dependencies on Linux and Windows systems.
- **Ubuntu 20.04**: Playwright now provides browser builds for Ubuntu 20.04.

## Browser Versions

- Chromium 86.0.4217.0
- Mozilla Firefox 78.0b5
- WebKit 14.0

## New APIs

- [`browser.version()`](https://playwright.dev/#version=v1.3.0&path=docs%2Fapi.md&q=browserversion)
- [`page.bringToFront()`](https://playwright.dev/#version=v1.3.0&path=docs%2Fapi.md&q=pagebringtofront)
- [`download.saveAs()`](https://playwright.dev/#version=v1.3.0&path=docs%2Fapi.md&q=downloadsaveaspath)
- [`request.postDataBuffer()`](https://playwright.dev/#version=v1.3.0&path=docs%2Fapi.md&q=requestpostdatabuffer)
- new `chromiumSandbox` option in [`browserType.launch()`](https://playwright.dev/#version=v1.3.0&path=docs%2Fapi.md&q=browsertypelaunchoptions), [`browserType.launchPersistentContext()`](https://playwright.dev/#version=v1.3.0&path=docs%2Fapi.md&q=browsertypelaunchpersistentcontextuserdatadir-options) and [`browserType.launchServer()`](https://playwright.dev/#version=v1.3.0&path=docs%2Fapi.md&q=browsertypelaunchserveroptions)
