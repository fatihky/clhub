**Breaking changes:**

Refactored `next-i18next-middleware` to behave more like common express
middleware, via #90.

Use of `next-i18next/middleware` has changed completely, and is [reflected in the docs](https://github.com/isaachinman/next-i18next/tree/3b72fdaed3c70e558e00879b19fdf520932178bc#3-project-setup).

This refactor allows for support of custom routes, improved query string support, and more.
