This patch release contains fixes for [a performance regression in `--build` mode](https://github.com/microsoft/TypeScript/issues/46204) by [only calling `realpath` on `package.json`](https://github.com/microsoft/TypeScript/pull/462090) files only when those files are known to exist on disk, and [to only perform this work under `--watch` mode](https://github.com/microsoft/TypeScript/pull/46211).
