## What's Changed
* feat: adds explicit AND, OR, NOT filters by @micheleriva in https://github.com/oramasearch/orama/pull/959

```js
const results = search(db, {
  term: "phone",
  where: {
    or: [
      {
        and: [
          { category: "electronics" },
          { price: { lt: 100 } }
        ]
      },
      {
        and: [
          { not: { brand: "random-brand" } },
          { price: { lt: 150 } }
        ]
      }
    ]
  }
})
```
