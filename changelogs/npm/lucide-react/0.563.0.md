## What's Changed

`aria-hidden` is by default added to icons components in all packages. This was already added to `lucide-react` before. 
Making icons accessible, you can add an `aria-label` or a `title`. See docs about [accessibility](https://lucide.dev/guide/advanced/accessibility).
