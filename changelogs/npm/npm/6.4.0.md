### DEPENDENCY UPDATES

A very special dependency update event! Since the [release of `node-gyp@3.8.0`](https://github.com/nodejs/node-gyp/pull/1521), an awkward version conflict that was preventing `request` from begin flattened was resolved. This means two things:

1. We've cut down the npm tarball size by another 200kb, to 4.6MB
2. `npm audit` now shows no vulnerabilities for npm itself!
